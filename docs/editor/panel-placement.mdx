# Panel Placement

## Description

Panels are placed on the roof automatically or manually.

## Features

- Auto layout
- Drag and drop
- Rotation and tilt
- Snap-to-grid

## Rules

- Panels must stay inside roof
- No overlap allowed
- Respect spacing rules

## Feedback

- Green: good placement
- Yellow: warning
- Red: invalid

## Edge Cases

- Small roof → suggest fewer panels
- Overlap → block placement
