# 🎯 UX & Micro-Interactions

As a React developer, these details are crucial for the "Look & Feel" of the Solar Editor.

### 1. Editor Feedback

- **Hover States**: Roof planes should highlight when the mouse is over them.
- **Warning Overlays**: Panels turn **Red** if they are outside the roof boundary or over an obstruction.
- **Snap-to-Grid**: Visual guides appear when a panel is aligned with a neighboring panel.

### 2. Drag & Drop Behavior

- Smooth transition when moving panels from the "Toolbar" to the "Roof".
- Undo/Redo (Ctrl+Z / Ctrl+Y) functionality for every panel placement.

### 3. Tooltips

- Instant info on a panel when clicked (Wattage, String ID, Orientation).
